# Workshop App

Interactive Attendee Gallery and Agentic Control Hub.

## Features

### AI-204: Danylo's Dashboard Widget & Feature Page
- **Widget**: `DanyloWidget` located at `src/components/widgets/danylo-widget/DanyloWidget.tsx`.
- **Feature Page**: `DanyloFeaturePage` located at `src/pages/danylo-feature/DanyloFeaturePage.tsx`.
- **Error Handling**: `ErrorBoundary` wrapper for graceful stream fallback.

## Getting Started

```bash
# Install dependencies
npm install

# Start dev server
npm run dev

# Run unit tests
npm test

# Type checking
npm run lint
```
